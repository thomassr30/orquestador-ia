# Simplificar (menos ruido, tarea principal más clara)
- Identifica la tarea principal; si no está clara, pregunta antes de quitar nada.
- Elimina repetición y decoración sin significado.
- Agrupa controles dispersos; unifica elementos repetidos (mismo patrón para lo mismo).
- Opciones ocasionales bajo demanda (expandible, "Más opciones"), no ocultas sin rastro.
- Conserva: labels claros, estados visibles e información necesaria para decidir.
- Comprueba el camino principal y los caminos menos frecuentes (lo movido a un disclosure sigue alcanzable).
- "Más audaz" / "más sobrio": cambiar contraste de escala, peso, color y espacio de forma coherente con la marca; nunca agregando efectos decorativos.
