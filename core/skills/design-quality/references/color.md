# Color
- **Cada color tiene un trabajo**: acción primaria, selección, estados (éxito, alerta, error, info), énfasis puntual. El resto, neutros.
- **Respeta la marca** y la paleta del proyecto; no la reemplaces ni tiñas todo.
- **Neutros con un leve matiz** (hacia el color de marca) en vez de negro/gris puros; fondos `#fff`/`#000` puros solo si el sistema lo define.
- **Contraste WCAG AA**: 4,5:1 texto normal, 3:1 texto grande (≥ 24 px o 18,7 px bold) y componentes/íconos significativos. Verifica sobre el fondo real (incluye hover, foco, deshabilitado, error y tema oscuro).
- **Texto sobre color**: usa un tono claro/oscuro del mismo matiz, no gris.
- **Nunca solo color** para comunicar estado: acompaña con ícono, texto o forma.
- **Tema oscuro**: superficies con niveles (no negro puro), acentos desaturados, mismo significado de colores.
- **Datos**: paleta categórica distinguible (también para daltonismo) y secuencial para magnitudes.
